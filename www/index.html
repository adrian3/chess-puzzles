Report a bug

  • Think you found an error in one of the puzzles? Sorry about that. While we have tried really hard to keep our database of puzzles error-free there still might be a few glitches. If you have a second would you mind sending us a note documenting the error you found? Thanks! Here's what to do:
  • 1. Figure out what puzzle number the error occurred in.
  • 2. Document what kind of error you found. Popular choices are: multiple mate options, valid moves showing as errors, and duplicate puzzle.
  • 3. This one is optional. Describe the error. The more info the better, but don't stress about it if you don't have time to explain what you are seeing.
  • 4. Finally, put that into an email and send it to:
    designer@adrianhanft.com
  • 5. That's it. I really appreciate your help and will release updates as soon as I can. Thank you very much for your help!
  • If you run into any issues like puzzles unlocking, email me at designer@adrianhanft.com and I can help you out.

Tutorial

  • Assuming you know the rules of chess, using this app should be relatively easy. Here are a few tips to get you started solving puzzles:
  • 1. To move a piece, first tap on it. This will highlight the piece with an orange outline.
  • 2. Now tap on the square that you want to move to. If this move doesn't correctly solve the puzzle you can try again. If it is the correct move, you continue on with the puzzle.
  • 3. If you make 3 wrong moves in a row a question mark "hint" icon will appear. Tapping on this icon will make the correct move for you.
  • 4. At the bottom of you screen at all times is a puzzle button. Tapping on this will remind you how many moves it will take to solve the current puzzle.
  • 5. That's it. Want to give it a try?
    Tap here for a simple example.
